# Clipboard Router App Store submission assets

This directory contains local draft metadata for the macOS App Store listing for
Clipboard Router 0.1.0 (build 1), bundle identifier
`com.clipboardrouter.ClipboardRouter`.

Nothing in this directory uploads, publishes, or modifies App Store Connect.
The text is ready to paste after the separate Mac App Store build is signed and
validated. URL fields point at the dedicated binary-release repository and must
be checked after that repository is published.

Before submission:

1. Confirm the product, support, and privacy-policy URLs resolve publicly.
2. Resolve the privacy-manifest/questionnaire discrepancy documented in
   `privacy-notes.md`.
3. Confirm the final Mac App Store build contains only features described in the
   listing and passes App Store validation.
4. Re-capture screenshots from that exact build if the visible UI changes.

The prepared screenshots are in
`../.artifacts/app-store-screenshots/`. Each is a true PNG at 1440 x 900 pixels.
