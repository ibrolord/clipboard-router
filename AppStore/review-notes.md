# App Review notes

Clipboard Router is a menu-bar application (`LSUIElement=true`). It does not
show a persistent Dock icon. After launch, use the Clipboard Router menu-bar
item to open the recent-clips menu or choose **Open Library**.

No account, subscription, or demo credentials are required to test the local
clipboard workspace.

Suggested review path:

1. Launch Clipboard Router and allow macOS pasteboard access if prompted.
2. Copy the text `Clipboard Router review sample` in TextEdit.
3. Open Clipboard Router from the menu bar and confirm the sample appears.
4. Choose **Open Library**, select the sample, save it, and create a note.
5. Start **Private Session**, copy a second sample, and confirm the session view
   explains that new clips remain only in memory. End the session before
   continuing.
6. Open **Vault**. Authentication is required before encrypted clip contents are
   revealed.

Clipboard Router never automatically submits a prompt, email, CRM update, or
other external action. A handoff copies the reviewed clip and opens the chosen
destination. Any final send remains under the reviewer's control.

The application includes Contacts, Calendars, and Location usage descriptions.
Those capabilities are invoked only after a user chooses the corresponding
reviewed action. Denying a permission does not prevent basic clipboard capture,
search, saving, notes, folders, Private Session, or Vault use.
